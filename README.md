Ответьте письменно: почему этот метод невозможно реализовать с обычными параметрами так, чтобы изменения были видны вызывающему коду?
потому что здесь изщменяются значения искомые

1. Что именно копируется при передаче параметра по значению? Объясните разницу для `int` и для объекта класса.

для int копируется само число, для объекта класса — ссылка на объект. Поэтому объект можно изменить через копию ссылки, но нельзя заменить исходную переменную.

2. В чём разница между `ref` и `out` с точки зрения обязательной инициализации переменной до и после вызова метода?

ref требует инициализации переменной до вызова, out — нет. При этом out обязательно должен получить значение внутри метода до его завершения.

3. Почему у `int.TryParse` используется именно `out`, а не `ref`, для параметра, куда записывается результат?

метод сам записывает результат в переменную, и её предыдущее значение не требуется.

4. Какую проблему решает `in`? Почему он интереснее для больших структур, чем для `int`?

передаёт параметр по ссылке только для чтения, избегая копирования. Особенно полезен для больших структур, поскольку они занимают больше памяти.

5. В каком порядке относительно обязательных параметров должны располагаться необязательные параметры?

Необязательные параметры должны располагаться после всех обязательных параметров

6. В чём преимущество именованных аргументов при вызове метода с несколькими необязательными параметрами?

Именованные аргументы делают вызовы понятнее и позволяют задавать значения параметров по имени, пропуская необязательные параметры и меняя их порядок.
